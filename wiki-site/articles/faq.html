Frequently Asked Questions

What is Mosaic Mod Manager?

A Linux-native mod manager supporting a wide range of games, built to bring feature parity with Windows-only tools.

Do I need Wine or Proton to run it?

No. Mosaic runs natively on Linux and manages mods for games running under Proton without requiring you to run the manager itself through Wine.

Which games are supported?

See the Adding a Custom Game page for how to register games beyond the built-in list.

My mods aren’t showing up in-game. What do I check first?

Confirm you’ve deployed your profile (see Deploy and Restore) and that the game’s data path is set correctly.
