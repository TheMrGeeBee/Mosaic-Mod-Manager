# Security Policy

## Supported Versions

Mosaic Mod Manager is a solo-maintained project with a single rolling
release line — there are no long-term-support branches. Only the most
recently released version (AppImage, Flatpak, or Nexus download) receives
security fixes.

| Version        | Supported          |
| -------------- | ------------------- |
| Latest release | :white_check_mark: |
| Anything older | :x:                 |

If you're reporting an issue on an older version, please update first and
confirm it still reproduces.

## Reporting a Vulnerability

**Preferred**: use GitHub's private vulnerability reporting — go to the
[Security tab](https://github.com/TheMrGeeBee/Mosaic-Mod-Manager/security/advisories/new)
and click "Report a vulnerability." This keeps the report private between
you and the maintainer until a fix is ready, and is the fastest way to
reach me directly.

**Alternative**: email mrgeebee@pm.me.

Please do not open a public GitHub issue for security vulnerabilities.

### What to expect

This is a solo-maintained project, so there's no formal SLA, but as a
target:

- Acknowledgement within a few days of your report.
- If accepted, a fix released as soon as reasonably possible, with credit
  in the release notes/changelog if you'd like it (or anonymously, your
  choice).
- If declined (e.g. not reproducible, out of scope, or working as
  intended), an explanation of why.

Thanks for taking the time to report responsibly.
